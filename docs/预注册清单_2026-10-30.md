- 标的：创业板指（399006），日收盘价
- 数据区间：2010-06-02 → 2026-10-29（3,983 个交易日）
- 基准日 t0：2026-10-29 收盘 2,517.59

  - 已知偏差：截至 10-29 已有 **5 个完整下跌周**；本周（10-26→10-30）若收跌则为第 6 周。事件匹配只用完整周，避免用未完成周的未来信息。

## 一、事件定义

对基准日 t0，记收盘价序列 P：

**P(H, Y) = P( 存在 h ∈ (0, H]，使得 max(P[t0+1 .. t0+h]) / P[t0] − 1 ≥ Y )**

即"未来 H 个交易日内，收盘价相对 t0 的最高涨幅达到 Y"。只用收盘价，不用盘中最高价。

参数网格（主口径加粗）：

| 编号 | H（交易日） | Y | 定位 |
|---|---|---|---|
| G1 | 20 | 3% | 弱反弹（敏感性） |
| **G2** | **20** | **5%** | **主口径** |
| G3 | 20 | 10% | 强反弹（敏感性） |
| G4 | 60 | 10% | 中期（敏感性） |

同时每个格子必须输出三项路径指标，缺一不可：
1. `maxdd`：窗口内相对 t0 的最大回撤（最坏时点跌幅）
2. `terminal`：到第 H 日的终点收益
3. `p_newlow`：窗口内是否跌破 t0 之前 120 日最低收盘价

## 二、条件集（5 个，先定后测）

| 编号 | 条件 | 备注 |
|---|---|---|
| C1 | 自 250 日最高收盘回撤 ≤ −40%，且为**首次触及** | 最贴近当前形态（−42.4%） |
| C2 | 连跌 ≥4 个完整周 **且** 60 日涨跌 ≤ −20% | 周线动量 + 深度 |
| C3 | 60 日涨跌 ≤ −25%（纯幅度，不看周数） | 检验"跌得多"本身 |
| C4 | 连跌 ≥3 个完整周 **且** 60 日涨跌 ≤ −12% | 宽口径，用来换取样本量 |
| C5 | 连跌 ≥5 个完整周 **且** 60 日涨跌 ≤ −25% | 最接近当前状态，预期样本极少 |

**事件不重叠处理**：同一条件集内，两个事件之间至少间隔 60 个交易日（冷却期），否则同一段下跌会被重复计数，人为放大样本量。

## 三、统计方法（预先锁定）

1. **基准率**：全样本逐日滚动计算，作为"什么都不看"的裁判。
2. **原始条件概率**：k/n，配 Wilson 95% 置信区间。
3. **贝叶斯收缩**（防止 n=1 输出 100%）：
   - 先验 Beta(α, β)，均值取该格子的基准率 p0，先验强度 n0 = **15** 个伪观测
   - α = n0·p0，β = n0·(1−p0)
   - 后验均值 = (α + k) / (α + β + n)，后验 90% 可信区间由 Beta 分位数给出
4. **证据强度**：后验均值与基准率之差（百分点）。|差值| < 5pp 视为"信号不可分辨"。
5. **多重比较**：5 条件 × 4 网格 = 20 个检验；在 5% 显著性水平下，纯随机也会出现约 1 个"显著"。报告中必须标注此事，单个显著结果不作结论。
6. **不做的事**：不做特征筛选、不做模型调参、不做样本外择优。L3 特征模型按约定推迟。

## 四、同构性分析（价格形态层）

1. 自动识别历史熊市段（自运行峰值回撤 > 30%，回撤回升至 −15% 以内视为该段结束）。
2. 每段计算形态向量：深度、历时、年化波动率、量能萎缩比（段末 60 日均量 / 峰值前 60 日均量）。
3. **同位置类比**（核心）：在每段历史熊市中，找到回撤**首次达到当前深度（−42.4%）**的那一天，看它之后的 20 / 60 / 120 日发生了什么。这是与今天最可比的口径——不是"跌到底之后怎样"（那有后视偏差）。
4. 限制：本版只做价格形态同构，**不做宏观驱动归因**。凡涉及"这次为什么跌"的判断，一律标注为待验证。

## 五、预先登记的失效条件

出现以下任一情况，本报告的统计结论应作废，不得引用：

1. 本次下跌被证实由流动性/信用事件驱动（而非估值与情绪修复）——均值回归统计对这类尾部系统性失效。
2. 交易制度发生变化（涨跌幅、T+0、减持规则等）。
3. 指数编制规则大幅调整，导致历史点位与今日不可比。
4. 单日出现 >7% 的跳空缺口（历史分位框架的样本内不存在这种冲击，模型外推无效）。
